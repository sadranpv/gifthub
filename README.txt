GiftHub - نسخه آماده انتشار روی GitHub Pages

فایل‌ها:
- index.html: صفحه اصلی
- store.html: فروشگاه
- cart.html: سبد خرید
- admin.html: پنل مدیریت

انتشار:
1) فایل ZIP را استخراج کنید.
2) تمام محتویات پوشه را مستقیماً در ریشه ریپازیتوری sadranpv/gifthub-site آپلود کنید (نه خود پوشه را).
3) در GitHub > Settings > Pages، شاخه main و پوشه /(root) را انتخاب کنید.
4) چند دقیقه صبر کنید و سایت را با Ctrl+F5 تازه‌سازی کنید.

نکته: این نسخه طراحی‌های HTML موجود را نگه می‌دارد و لینک‌های داخلی اصلی را به صفحات مستقل وصل می‌کند. فایل‌های PNG جداگانه در فایل‌های قابل دسترسی این گفتگو نبودند؛ تصاویر خارجی موجود در HTML همچنان به اینترنت وابسته‌اند. پنل مدیریت و پرداخت واقعی/درگاه بانکی یا موجودی انبار سمت سرور نیستند و برای فروش واقعی به بک‌اند امن نیاز دارند.
